## 建设方式与当前进度

来源有据 → 加工有规则 → 使用有说明 → 更新有版本。

以真实经济数据为基础，突出中国企业与家庭案例。AI 辅助资料整理与代码准备，人工核对来源、变量含义和结果。

- **本地准备完成**：CSMAR、hybrid、hkfamily、shoppers、donation、gym、WDI 七套数据包已整理并配有字典、规则与核验记录。
- **公开阅读可用**：本仓库提供案例说明、教学任务与官方资源入口，不提供数据下载。
- **后续配套计划**：逐步组织章节练习、读取程序和使用指南；当前没有统一下载包、成套 Notebook 或已发布的数据版本。
- **GMD 自主获取**：获取流程已验证，读者自行从官方渠道获取并记录版本；不计为第八套本地数据包。

本地数据准备完成不等于原论文全文复现，也不等于所有资料可公开再分发。机构数据库须按授权访问，第三方资源按各自条款获取与引用。

## 本仓库的文件

`index.html` 为案例目录，`cases/` 包含八个案例详情页，`guide.html` 为使用指南，`styles.css` 为本地样式，`ACCESS.md` 为获取与边界说明，`.nojekyll` 用于静态托管。页面不依赖外部字体、脚本或图片。

本仓库只管理公开展示材料；原始及整理数据、第三方论文 PDF、私人材料、内部日志与环境文件均不在此仓库。未为本站内容另行授予开放许可证；第三方资料权利归原权利人所有。
